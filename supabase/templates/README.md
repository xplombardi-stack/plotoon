# E-mails do login

Cole o conteúdo destes arquivos no Supabase: Authentication → Emails → Templates.

| Modelo no Supabase | Assunto | Arquivo |
| --- | --- | --- |
| Confirm signup | Confirme sua conta no Plotoon | confirmar-conta.html |
| Reset password | Troque sua senha do Plotoon | trocar-senha.html |

O nome de quem envia (hoje "Supabase Auth") só muda com um servidor de e-mail próprio (SMTP), que precisa do domínio do site.
